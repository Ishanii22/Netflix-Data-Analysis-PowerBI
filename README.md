# 📺 Netflix Data Analysis - Power BI

This project provides a comprehensive analysis of the **Netflix Movies and TV Shows** dataset. Using **Power BI**, I transformed raw data into an interactive dashboard to uncover insights about content distribution, ratings, and release trends.

## 🚀 Project Overview
The goal of this analysis is to explore the Netflix library and understand:
* The balance between **Movies** vs **TV Shows**.
* Content growth over the years.
* Top performing **Genres** and **Countries**.
* Distribution of content **Ratings**.

## 📊 Key Features
* **Interactive Dashboard:** Filter by Year, Genre, and Country.
* **KPI Cards:** Total Movies, Total TV Shows, and Total Ratings.
* **Visualizations:**
    * Content added over time (Area Chart).
    * Top 10 Genres (Bar Chart).
    * Ratings Distribution (Donut Chart).
    * Global content reach (Map Visualization).

## 🛠️ Tools Used
* **Power BI Desktop:** Data Cleaning (Power Query), Modeling, and Visualization.
* **Dataset:** Netflix Dataset.
* **DAX:** Created custom measures for advanced calculations.
